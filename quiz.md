# Phishing Awareness Quiz - Educational Lab

Instructions: This quiz is part of Social Engineering Awareness Training.

Q1. What is the first thing you should check in a suspicious email?
Ans: The sender's domain name and email address.

Q2. Why should you hover over a link before clicking?
Ans: To see the real destination URL and check if it is safe.

Q3. Will a legitimate IT department ever ask for your password or OTP via email?
Ans: No, never.

Q4. What is the correct action if you receive a phishing email?
Ans: Report it to the IT security team and delete it. Do not forward or click.

Q5. What is example-secure-lab.local used for in this project?
Ans: It is a fictional, safe domain created only for lab training. It does not impersonate any real company.

Q6. What is Social Engineering?
Ans: Manipulating people to gain confidential information, not hacking computers.
