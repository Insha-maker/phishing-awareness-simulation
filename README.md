# Social Engineering Awareness - Phishing Simulation

A cybersecurity awareness project focused on social engineering and phishing email detection using Kali Linux.

## 🎯 Project Objectives
This is an educational project to teach users how to identify and avoid phishing attacks. All simulations are done in an isolated lab environment.

## ⚖️ Ethics and Authorization Policy (Most Important)
- This project is for EDUCATIONAL PURPOSE ONLY
- No real users are targeted without written consent
- No real company (Google, Microsoft, Banks) is impersonated. All templates use fictional domain `example-secure-lab.local`
- No real passwords are collected or stored. The landing page clearly states "This was a simulation for training"
- All tests are performed on lab accounts owned by us
- Participants are debriefed after the simulation

## 🔧 Lab Setup Documented
- Kali Linux VM (Isolated Network)
- GoPhish Framework for simulation
- All IPs are internal lab IPs (e.g., 192.168.x.x)

## 📧 Fictional Email Template (Safe Example)
Subject: Security Training - Please Review Your Training Portal

Body: Hello, This is your annual security awareness training reminder from Example Lab IT Team. Please visit your training portal to complete the module. Do not share your password with anyone.

Link: http://example-secure-lab.local/training

This is NOT a real company email.
